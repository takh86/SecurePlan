# API Design – öffentliche Übersicht

Stand: 07.10.2026. Die interne Designbaseline hat Phase 8.11 erreicht. Produkt-API-Design und implementierte Endpunkte werden getrennt ausgewiesen.

Öffentliche Einstiegspunkte: [Resource-Analyse](phase-8-1-resource-analysis-draft.md) und [bereinigte Designzusammenfassung](phase-8-2-rest-endpoint-design.md). Historische Dokumente beschreiben ihren jeweiligen damaligen Stand.

Das Ziel sind nachvollziehbare REST-Ressourcen, explizite Validierung, konsistente Fehlerbehandlung und geeignete Parallelitätskontrollen. Vollständige interne DTO-/Endpoint-/Securityverträge sind nicht veröffentlicht. Aktuell implementiert sind Starter und technische Healthchecks, keine vollständige Business-API.
