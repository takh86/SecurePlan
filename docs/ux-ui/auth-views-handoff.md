# Identity-UX – öffentliche Übersicht

Die geplanten Views umfassen Login, Account-Aktivierung und Passwortwiederherstellung. Sie benötigen verständliche Lade-, Fehler- und Erfolgszustände sowie Tastaturbedienung, zugängliche Feldlabels und Unterstützung für Passwortmanager.

Aktuell ist die Frontend-Anwendung ein Starter; diese Screens sind noch nicht implementiert. Interne Sicherheitsabläufe und genaue technische Handoffs werden separat dokumentiert.
